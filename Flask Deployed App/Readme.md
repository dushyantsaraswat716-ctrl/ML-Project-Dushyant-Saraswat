# 🌿 Plant Disease Detection - Web Application

This web application uses a Deep Learning Convolutional Neural Network (PyTorch) trained on the PlantVillage dataset to classify crop leaf diseases in real-time.

---

### 🚀 Quick Start Instructions:

1. **Install Requirements:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Verify Weights File:**
   Ensure `plant_disease_model_1_latest.pt` is present in this folder (already bundled/downloaded).

3. **Start the Web Server:**
   ```bash
   python app.py
   ```

4. **Access the App:**
   Open your browser and navigate to `http://127.0.0.1:5000`
